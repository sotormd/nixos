# rice

A home-manager module which configures:

|                   |                                                       |
|-------------------|-------------------------------------------------------|
| display server    | `wayland`                                             |
| compositor        | `swayfx`                                              |
| bar               | `waybar`                                              |
| widgets           | `eww`                                                 |
| launcher          | `rofi`                                                |
| notifications     | `dunst`                                               |
| terminal emulator | `foot`                                                |
| colorscheme       | [`nord`](https://github.com/sotormd/colors)           |
| wallpapers        | [`wallpapers`](https://github.com/sotormd/wallpapers) |
| gtk theme         | `Nordic-darker`                                       |
| gtk icons         | `Nordzy-dark`                                         |
| gtk cursor        | `Simp1e-Nord-Dark`                                    |
| font              | `IBM Plex`                                            |
| screenshots       | `grimshot`                                            |

See [flake.nix](../flake.nix) for example usage.
