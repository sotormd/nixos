# hosts

Entrypoint for the various outputs.

```console
hosts
├── default.nix       # entrypoint
├── droid.nix         # nix on droid
├── imageGnome.nix    # gnome image
├── imageMinimal.nix  # minimal image
├── imageSD.nix       # sdcard image
├── imageSDRemote.nix # sdcard image (remote)
├── laptop.nix        # laptop configuration
└── server.nix        # server configuration
```
