# profiles

profiles are high-level collections of modules

purely a ease-of-use feature

## deskspec

for the machine-workstation desktop specialisations, so it contains EVERYTHING
for a base system

## desktop

sway desktop for machine-workstation, includes all required apps and services

## image

base configuration for image-* roles

## laptop

for uefi laptops, things like systemd-boot, secure boot, auto-cpufreq and wpa3

## machine

base configuration for all machine-* roles

## raspi

for raspberry pi 4b, uboot and quiet boot

## selfhost

selfhosted services for machine-server

## svcvm

for service virtual machines
